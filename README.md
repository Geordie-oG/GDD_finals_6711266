# Three in One Game

A small Unity C# practice project for the Game Design and Development final. It combines a driving game, flying game, and sumo game through one shared menu system.

## Run

Open the project in Unity 6, then open `Assets/Scenes/MainMenu.unity` and press Play.

## Controls

- **Main Menu:** click a game button or Exit.
- **Driving:** W/S or Up/Down to drive; A/D or Left/Right to steer.
- **Flying:** Space to flap upward; A/D or Left/Right to steer.
- **Sumo:** W/A/S/D or arrow keys to move and push the other balls.
- **Every game:** Escape opens the pause menu. Resume continues, Restart reloads the current game, and Back to Main Menu returns to the title screen.

The project uses only built-in Unity primitives and readable C# scripts so it is easy to demonstrate and explain.
